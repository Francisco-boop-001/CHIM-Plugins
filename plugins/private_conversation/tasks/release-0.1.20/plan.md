Prepared 2026-10-16 for the root-owned PCV source and publication gates. This plan records the authorized release boundary and the accepted duplicate-copy design; it does not authorize a build or publication before the lead gate.

## Goal and approved design contract

Prepare PCV 0.1.20 as an ALPHA release for the existing Plugin Manager discovery route. Keep CHIM core and Mind Poisoning separate and preserve the existing core compatibility reference.

Root approved a new server/installation_guard.php ownership helper. It deterministically prefers the stable private_conversation folder over the repository-path copy. Any single unguarded 0.1.19 copy remains preferred so a new installation defers safely regardless of load order. All seven hooks must use the guard; action declarations must be conditional; inactive UI requests must return HTTP 409 before mutation, refresh, or log side effects; CLI diagnostics must identify the physical owner. A mixed 0.1.20 installation stays inactive until the old duplicate is removed. Documentation must state that state is not migrated automatically.
