# Private Conversation 0.1.4 — PRE-ALPHA

Part of **World of Drama-Llama**. Direct a pair of nearby CHIM AI characters, or ask one character to think aloud. Apparently the Dragonborn does not need to chair every conversation in the province.

## Included

- Pair/solo controls, optional player inclusion in pair mode, and excluded or generic silent bystanders.
- Next-Standard-input activation: player-excluded input becomes CHIM scene instruction, initial responder is selected explicitly and current nearby/audience context is replaced.
- Existing no-chat CHIM background presence feed with 15-second visible-page polling and a projected 45-second activity lease; no separate Papyrus/ESP companion is required.
- Exact last-output registration and correlated speech-ACK integration with Mind Poisoning 0.1.12 for optional solo opinion reassessment. Pair gossip retains the listener-to-third-party path.
- Private operational logging/CLI diagnostics, current Drama-Llama artwork, informative operating/developer documentation and multi-format packages.
- Native trailing-carriage-return ACK ID normalization with strict rejection of interior corruption.

## Install

Choose one source: plain MO2 ZIP, manual DWPkg sync, or repository tar ingestion. Replace older enabled versions; do not stack them. Verify SHA256SUMS and the actual installed manifest/version. The tar has one `private_conversation/` wrapper stripped once; the MO2 ZIP contains `CHIM/server-plugins/private_conversation/0.1.4.dwpkg`. Full instructions are in the plugin README.

## Read before starting the drama

ARM and END stage changes for the next eligible ordinary Standard input; the browser does not start speech. Solo produces one generated response per eligible input. Pair rechat depends on CHIM. Close/Whisper are blocked while active; Director and an early rolemaster child path remain outside the scoped guards.

Only current nearby/audience context is scoped. Memories, history, profiles and other retained context may mention excluded people. Generic silent scenery does not suppress vanilla greetings. No physical privacy, exact earshot, native-facing or model-compliance guarantee is made. The nearby feed is broader than the precise player audience and cannot distinguish same-name references.

Optional opinion effects require compatible enabled Mind Poisoning, valid identity, unlocked processing and a genuine exact correlated ACK. A client-reported line attempt is not proof of audio/hearing. Solo registers only the last emitted chunk. Unchanged evidence cannot repeatedly accumulate a solo change, and zero is a valid result.
