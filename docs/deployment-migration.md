For MO2 users, the v0.1.19 Mind Poisoning ZIP is the recommended install. Its root `meta.ini` records version and source, and it contains the versioned schema-4 DWPkg at `CHIM/server-plugins/mind_poisoning/0.1.19.dwpkg`; no separate package download or manual insertion is needed. Metadata does not guarantee that MO2's Skyrim content warning is gone or prove CHIM sync. The raw DWPkg is an advanced alternative for manual CHIM file sync; `mind_poisoning.tar.gz` is an advanced server archive for existing explicit manifest/channel installs. These are independent routes, not three required downloads. `SHA256SUMS.txt` verifies downloaded bytes but does not install a package. GitHub's autogenerated Source code archives are not installers.

CHIM's current manifest-free Plugin Manager discovery requires a stable release with the `chim-plugin.tar.gz` asset and ignores prereleases. Mind Poisoning 0.1.19 is PRE-ALPHA, so that discovery path does not offer it. The repository's explicit `server/manifest.json` candidate channel is a separate, existing manifest route. See the [official CHIM Plugin Guide](https://dwemerdynamics.com/chim/plugin-guide.html) for current discovery and package rules.

Mind Poisoning remains developed at this repository root. Its embedded `plugins/private_conversation/` tree is a pinned integration fixture and is not included in the Mind Poisoning runtime package. The canonical Private Conversation authoring tree is the [CHIM-PrivateConversation deployment repository](https://github.com/Francisco-boop-001/CHIM-PrivateConversation); the sibling historical checkout is not the source for future releases. Of the 195 published PCV 0.1.15 paths, 194 match byte-for-byte; the sole tag-path exception is the preserved dirty `tasks/logging-improvements-plan.md`. The working copy also retains two paths outside the PCV tag: `tests/autonomous_presence_check.php`, tracked in this repository, and the ignored local cache `scripts/__pycache__/build-package.cpython-312.pyc`; the cache is not part of a clean source export. The five-case MP observer/importer pass was run before this pin while the working-tree fixture loaded PCV 0.1.12; it has not been rerun against PCV 0.1.15. The immutable published MP 0.1.16 tag retains PCV 0.1.8 at that path.

## Existing-install migration

### Historical migration from Mind Poisoning 0.1.13

The old 0.1.13 channel used a `<version>` package URL under `CHIM-Plugins`. Its version-matched 0.1.14 compatibility release was the migration bridge to the dedicated deployment repository. That bridge's package manifest identifies `Francisco-boop-001/CHIM-MindPoisoning`; verify the installed version and `git_repo` before relying on later updates through the dedicated repository's explicit manifest channel. The old 0.1.13 tag and assets remain unchanged. New MO2 installs use the current MO2 ZIP and do not need this bridge.

### Private Conversation 0.1.4 and 0.1.5

Both published manifests point to literal, version-specific `CHIM-Plugins` package assets: [0.1.4](https://github.com/Francisco-boop-001/CHIM-Plugins/releases/tag/private_conversation-v0.1.4) and [0.1.5](https://github.com/Francisco-boop-001/CHIM-Plugins/releases/tag/private_conversation-v0.1.5). In particular, 0.1.5 does not substitute a future version into its package URL, so its Plugin Manager update button cannot migrate itself to the new repository. Keep the 0.1.4 and 0.1.5 assets unchanged. Replace the existing PCV server package once with 0.1.17 using the versioned `.dwpkg` asset or a supported installer channel configured for the exact `Francisco-boop-001/CHIM-PrivateConversation` repository. Then verify the installed manifest reports version `0.1.17` and that `git_repo` value. The standalone 0.1.14 manifest reads the dedicated repository's `main/server/manifest.json` and uses a version-substituted release URL, so later releases can update through that channel after the versioned assets and `main` manifest are advanced. The [0.1.8 `CHIM-Plugins` bridge](https://github.com/Francisco-boop-001/CHIM-Plugins/releases/tag/private_conversation-v0.1.8) remains a historical versioned download, not a way for the old 0.1.4/0.1.5 literal URLs to self-migrate.

### Private Conversation 0.1.8 state migration

Before updating, quiesce old PCV requests and keep HTTP access restricted through the first state resolution. Migration runs on first state access, not installation. The default state path uses a validated operating-system temporary root separate from `PCV_LOG_DIR`; the operating system may clean it. A valid legacy state directory moves only by atomic `rename()` when the destination is absent and both paths share a filesystem. Migration fails closed on corrupt, unsafe, unknown or conflicting data and on `EXDEV`; the legacy source remains in place, with no copy, merge or reset.

The private path depends on the effective PHP worker UID, canonical extension path, and temporary-root namespace. A CLI temp directory or matching UID does not establish the HTTP worker's path; separate namespaces such as systemd `PrivateTmp` can resolve different roots. Until migration succeeds, legacy state may remain HTTP-readable if server overrides are ignored, so the package is not an independent access boundary. This source and isolated-fixture evidence does not establish installed CHIM or PHP-FPM behavior.

For either plugin, use one server-package route at a time. Disable or remove older enabled MO2/file-sync copies before switching to Plugin Manager; do not stack versions. A release page or Plugin Manager listing alone does not prove which code is installed.

## Plugin Manager routes and verification limits

The current manifest-free discovery route uses the GitHub `chim-plugin` topic and a stable release asset named `chim-plugin.tar.gz`; drafts and prereleases are ignored. Mind Poisoning 0.1.19 is a prerelease, so it is not installable through that discovery route. Existing manifest/channel clients remain a separate supported path. A release page, asset, or checksum alone does not prove a package is installed or synchronized.

The historical cross-plugin check remains source-bound: the immutable Mind Poisoning 0.1.14 tag retains its matching Private Conversation 0.1.6 snapshot and its evaluator-to-observer-to-importer fixture; this PCV bridge does not retag or rebuild MP 0.1.14. The standalone PCV 0.1.15 `reflection_registry_check.php` requires matched MP 0.1.16 evaluator/API fixtures. The MP observer fixture dynamically loads the embedded snapshot: its recorded five-case pass used PCV 0.1.12 before this pin, and no 0.1.15 run is claimed. The immutable published MP 0.1.16 tag retains PCV 0.1.8 at that path. A PCV-only export cannot provide MP source. Runtime packages include only each plugin's explicit server-file allowlist, not the other plugin or tests.

These repository, manifest, fixture, and package checks do not establish clean live installation, proxy/authentication topology, live database/provider behavior, or Skyrim speech/audio delivery. Both candidates remain PRE-ALPHA; the compatibility reference is unchanged and is not an installation pin.
