# Mind Poisoning v0.1.21 — BETA CANDIDATE

This release is labeled **BETA CANDIDATE** and is experimental for discovery through CHIM's newer topic-based Plugin Manager. Its GitHub release is configured as a standard release so the discovery service can see `chim-plugin.tar.gz`. Apparently “stable” is a switch the catalog needs; it is not a magic wand for the test report.

Mind Poisoning can let an NPC revise their opinion of a named person after hearing praise, criticism, or a balanced account from someone else. A listener can disbelieve the speaker or make no change; gossip does not become shared world truth. A compatible companion can also request actor-owned solo reflection from an exact registered line. The optional relationship-type change is conservative: one native CHIM type at a time, custom types stay protected, and enduring `romantic`, `familial`, and `professional` types are not replaced by temporary reactions.

## Choose one installation route

- **MO2:** use the [plain MO2 ZIP](https://github.com/Francisco-boop-001/CHIM-MindPoisoning/releases/download/mind_poisoning-v0.1.21/mind_poisoning-0.1.21-mo2.zip). It contains the matching DWPkg, so do not add another package copy.
- **Experimental CHIM topic discovery:** in a CHIM build whose Plugin Manager supports the `chim-plugin` topic, choose **Refresh Plugins → Mind Poisoning → Install/Update**, confirm the installed tag is `mind_poisoning-v0.1.21`, then open **Plugin Page**. The manager fetches the flat [`chim-plugin.tar.gz`](https://github.com/Francisco-boop-001/CHIM-MindPoisoning/releases/download/mind_poisoning-v0.1.21/chim-plugin.tar.gz); do not manually upload that archive. The pinned `cf5030f` core does not have this discovery feature, and an end-to-end .21 install through this route has not been verified.
- **Existing explicit manifest/channel install:** use [`mind_poisoning.tar.gz`](https://github.com/Francisco-boop-001/CHIM-MindPoisoning/releases/download/mind_poisoning-v0.1.21/mind_poisoning.tar.gz).
- **Manual CHIM file sync:** use the versioned [DWPkg](https://github.com/Francisco-boop-001/CHIM-MindPoisoning/releases/download/mind_poisoning-v0.1.21/mind_poisoning-0.1.21.dwpkg).

Pick one route for a server. Back up the server database and configuration before replacing an installation. MO2's game-content warning and package metadata do not prove that CHIM read or synchronized a package. The release's `SHA256SUMS.txt` verifies bytes; GitHub's autogenerated source archives are not installers.

## What changed

This candidate carries 0.1.20's optional single CHIM relationship-type judgments and canonical Player relationship handling. It adds global API declarations and a root Plugin Page entrypoint for the new discovery route. The `globals.php` hook exposes the existing reflection APIs before companion request hooks, with reflection API v1 and reply API v2 unchanged. The logger normalizes the exact `mind_poisoning-v0.1.21` release tag to semantic version `0.1.21` while leaving ordinary semantic versions intact. The legacy explicit manifest keeps its existing `ext/mind_poisoning/dashboard.php?local=1` configuration URL. The generated site-discovery route uses the separate root `index.php` entrypoint.

An isolated relocated compatibility check loaded the vendored PCV loader snapshot through the preloaded API and checked log parsing for the release-tag version. This does not represent a full run of the current PCV runtime or an installed cross-plugin session. Actual installed PCV integration remains unverified.

Reviewed newer manager source uses `ext/CHIM-MindPoisoning` for a clean topic-discovery install. When it recognizes an existing folder with the same valid `git_repo`, it reuses that folder in place instead of renaming it. A legacy folder with an unknown source can remain. This was not verified as a live migration. If the manager reports an unexpected or duplicate folder, stop and inspect it; do not stack packages or delete a folder blindly. See the [deployment and migration guide](../docs/deployment-migration.md).
